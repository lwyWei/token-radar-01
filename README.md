Token Radar ranks pre-token DeFi protocols by an implied value derived from a sealed DefiLlama snapshot: TVL, seven-day growth, how long the protocol has run with no token, and how many chains it spans. The board covers all 40 watchlist protocols plus 160 early pre-token protocols below the floor, and every row carries a seven-step farm plan with costs and times. The dashboard is sortable and filterable, with a per-protocol detail view and a model sandbox that re-ranks the board live.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
